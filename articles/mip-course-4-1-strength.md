## 定式化とは「多面体の選択」である

2-1の機械問題($x+y \le 6$、$5x + 9y \le 45$、整数)をもう一度使います。整数の実行可能解は下図の**濃い青の点**です。MIPの定式化とは、この点集合を**囲む多面体をひとつ選ぶ行為**にほかなりません。同じ点集合を囲む多面体は無数にあります。

![整数包](/images/mip-course-4-1-strength/fig1_hull.png)

- **オレンジ**: 元の制約が作る多面体(=LP緩和の実行可能領域)
- **青**: 囲み方の理想形——整数点集合の凸包、**整数包(integer hull)**と呼びます。頂点がすべて整数点なので、LPを解くだけで整数最適解が出ます(割当問題(3-1)が最初からこうでした)

2つの多面体の**隙間(オレンジの三日月部分)が、そのままソルバーの損失**です。LP最適(赤い星)はこの隙間に座っており、実測でIP=40に対しLP=41.25、ギャップ3.1%。分枝限定法はこの隙間を分枝とカットで削る作業に時間を使います。

そこで定式化の優劣をこう定義できます。

> 定式化Aの多面体が定式化Bの多面体を**包含**するとき、Bの方が**強い**。
> 整数包に近いほど強く、強いほどLP緩和の嘘が減り、刈り込みが効く。

**変数や制約の数は物差しではありません。多面体の締まり具合が物差しです。** ロットサイジングのFL形(3-4)は変数を $T$ 個から $T^2/2$ 個に増やして圧勝しました。太った定式化が強いことは普通にあります。

## この教材の実測ギャップ総ざらい

これまで測ってきたLPギャップを1枚にまとめます。

![実測ギャップ一覧](/images/mip-course-4-1-strength/fig2_gaps.png)

| 問題 | 弱い書き方 | 強い書き方 | 効果(実測) |
| ---- | ---- | ---- | ---- |
| 割当(3-1) | — | ギャップ**0%**(完全単模) | LPだけで解ける |
| ビンパッキング(3-5) | **24.4%**(総量÷容量と同値) | パターン定式化(5-1) | 0.11秒で最適証明 |
| 施設配置(2-4) | **46.2%**(集約Big-M) | **0%**(個別リンク) | 16.3→0.5秒 |
| ロットサイジング(3-4) | **85.8%**(Big-M) | **0%**(FL再定式化) | 39.7→14.9秒(能力付き) |

眺めると法則が見えます。

- **ギャップの主犯はほぼ毎回Big-M**。連続量とバイナリのリンクを緩く書いた場所から嘘が生まれる
- 強い書き方の共通手筋は「**大きなくくりを個別にばらす**」(集約リンク→顧客ごと、総需要M→需要ごとの割当変数)
- 極端な場合、強い定式化はギャップ0%=**LPの速度でMIPが解ける**

## 実務の習慣:モデルを書いたらまずギャップを測る

「このモデル、遅い。なぜ?」の切り分けは、LPギャップを測るのが最短です。測り方は簡単で、整数条件を連続に変えたモデルを解いて比べるだけです。

```python
def measure_lp_gap(build):
    """build(relax: bool) -> Model を渡すと LPギャップを実測して返す"""
    m_ip = build(relax=False); m_ip.optimize()
    m_lp = build(relax=True);  m_lp.setPresolve(0); m_lp.optimize()
    ip, lp = m_ip.getObjVal(), m_lp.getObjVal()
    return ip, lp, abs(ip - lp) / abs(ip) * 100
```

(小さな代表インスタンスで測るのがコツです。本番規模でIPが解けないから困っているわけなので。)

読み方の目安:

| ルートLPギャップ | 診断 |
| ---- | ---- |
| ほぼ0% | 定式化は優秀。遅いなら規模・対称性・数値を疑う(4-3) |
| 数%〜20% | 普通。ソルバーのカット(次回)で埋まることが多い |
| 50%超 | **定式化に構造的な弱さ**。Big-Mの緩み、リンクの集約を探せ |

なお2-3で見たとおり、SCIPのログ自体もこの情報をくれます。根ノードの `dualbound`(カット追加後)と最終解の差が、**ソルバーが化粧した後の実効ギャップ**です。自分で測った素のLPギャップと比べると、「ソルバーのカットがどれだけ隙間を埋めたか」まで見えます。

## 強くするための手筋カタログ

これまでの実例から抽出した、緩和を強くする4つの手筋です。

1. **Mを物理限界まで絞る**(2-4, 3-4)。「この変数は最大いくつになりうるか」を業務知識で答える。1行で2.7倍の実測
2. **集約リンクを個別リンクにばらす**(2-4)。$\sum_j x_{ij} \le M y_i$ より $x_{ij} \le y_i$ ×顧客数。制約は増えるが多面体は締まる
3. **既知の強い再定式化を調べる**(3-4)。ロットサイジングのFL形のように、定番問題には研究済みの強い形がある。「(問題名) extended formulation / tight formulation」で探す
4. **ネットワーク構造を守る**(3-1)。完全単模な骨格を壊す制約は、本当に必要なものだけに

そして5つ目の手筋が、**足りない不等式を後から足す**——切除平面です。整数包とLP領域の隙間を、平面でスライスして削っていく。実はSCIPは毎回これを自動でやっています(2-3のログの `cuts` 列)。次回はその中身を開けて、**自作のカット**でギャップが埋まる瞬間を観察します。

## まとめ

- 定式化=**整数点集合を囲む多面体の選択**。理想は整数包(頂点が全部整数)
- 優劣の物差しは変数・制約の数ではなく**多面体の締まり具合**(包含関係)
- 実測ギャップ総ざらい: 0%(割当)〜85.8%(ロットサイジング標準形)。主犯はBig-M
- **モデルを書いたらまずLPギャップを測る**。50%超なら定式化を疑う
- 手筋: Mを絞る/個別リンク/既知の強い再定式化/構造温存/カット(次回)

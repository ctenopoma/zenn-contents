## 題材:2製品の生産計画

小さな工場で製品Aと製品Bを作ります。

| | 製品A(1個あたり) | 製品B(1個あたり) | 使える量 |
| ---- | ---- | ---- | ---- |
| 材料 | 2 kg | 3 kg | 24 kg |
| 機械時間 | 4 時間 | 2 時間 | 32 時間 |
| 利益 | 5 万円 | 4 万円 | |

さらに製品Bは需要の都合で**6個までしか売れない**とします。AとBを何個ずつ作ると利益最大でしょうか。

まず前回までの言葉で3部品に翻訳します。

- **変数**: Aの生産量 $x$、Bの生産量 $y$(今回は連続量とします。0.5個も作れる世界)
- **制約**:
    - 材料: $2x + 3y \le 24$
    - 機械: $4x + 2y \le 32$
    - 需要: $y \le 6$
    - 作る量は負にならない: $x \ge 0,\ y \ge 0$
- **目的関数**: 利益 $5x + 4y$ を最大化

変数が2つしかないので、この問題は**平面上に描けます**。ここからが本題です。

## ステップ1:制約を描くと「実行可能領域」が残る

制約は全部「一次式 ≤ 定数」の形です。一次式の不等式が表す領域は、直線で区切られた**半平面**(直線の片側)です。5つの制約の半平面を全部重ねると、共通部分として五角形が残ります。

![実行可能領域](/images/mip-course-1-1-lp-graphical/fig1_region.png)

この水色の五角形が**実行可能領域(feasible region)**。「材料も機械も需要も守れる生産計画」の全体です。この中の点ならどれを選んでも実行できます。問題は、この無数の点のどれが一番儲かるかです。

## ステップ2:利益の「等高線」を滑らせる

利益 $5x + 4y$ が同じ値になる点の集まりは直線です(例えば利益20万円の線は $5x+4y=20$)。地図の等高線と同じ発想なので、これを**等高線**と呼びます。

利益を20万、30万、40万……と増やしていくと、等高線は右上へ**平行移動**していきます。

![等高線を滑らせる](/images/mip-course-1-1-lp-graphical/fig2_contour.png)

等高線を右上に滑らせ続けると、いつか実行可能領域から完全に離れてしまいます。**離れる寸前、領域と最後に接している点**——それが最適解です。この図では $(6, 4)$、利益46万円。それより上の等高線は領域と交わらない、つまり「利益47万円を出せる実行可能な計画は存在しない」ことも同時にわかります。

これが「最適化を解く」ことの幾何学的な意味です。**良い解を見つけることと、それ以上が無いと確かめることが、1枚の絵の中で同時に起きています。**

## ステップ3:最適解はなぜ「角」に来るのか

等高線は直線で、領域の縁も直線です。直線の等高線が多角形から離れる寸前に接する場所は、ほとんどの場合**頂点(角)**になります。

つまり、無数にある実行可能な点のうち、**チェックすべきは頂点だけ**。この問題の頂点は5個しかありません。全部調べてみます。

![頂点の総当たり](/images/mip-course-1-1-lp-graphical/fig3_vertices.png)

| 頂点 | 意味 | 利益 |
| ---- | ---- | ---- |
| (0, 0) | 何も作らない | 0万円 |
| (8, 0) | Aだけ(機械を使い切る) | 40万円 |
| **(6, 4)** | **材料も機械も使い切る** | **46万円** |
| (3, 6) | Bを需要上限まで | 39万円 |
| (0, 6) | Bだけ | 24万円 |

最大は頂点 $(6,4)$ の46万円。「無限の選択肢から選ぶ問題」が「5個の候補から選ぶ問題」に化けました。これが線形計画が"解ける"根本的な理由です。

ひとつだけ例外があります。等高線が領域の**辺とぴったり平行**な場合、角ではなく辺全体が最適になります。

![辺が最適になる場合](/images/mip-course-1-1-lp-graphical/fig4_edge.png)

利益係数を変えて $4x+6y$ にすると、等高線が材料制約と平行になり、辺上の点はどれも利益48万円で最適です。ただしこの場合も**辺の両端は頂点**なので、「頂点だけ調べれば最適値は必ず見つかる」という結論は崩れません。

## SCIPで答え合わせ

同じ問題をPySCIPOptで書いて確かめます。

```python
from pyscipopt import Model

m = Model("production")
x = m.addVar("x")            # デフォルトで x >= 0 の連続変数
y = m.addVar("y")
m.addCons(2*x + 3*y <= 24)   # 材料
m.addCons(4*x + 2*y <= 32)   # 機械
m.addCons(y <= 6)            # 需要
m.setObjective(5*x + 4*y, "maximize")
m.optimize()
```

実行結果です。

```text
status: optimal
x = 6.0 , y = 4.0
利益 = 46.0 万円
```

絵で求めた答えと一致しました。あわせて、最適解が各資源をどれだけ使っているかも見ておきます。

```text
材料: 24 / 24 kg   ← 使い切り
機械: 32 / 32 時間  ← 使い切り
需要: y = 4 / 6 個  ← 2個ぶん余裕がある
```

最適解の位置で**ぴったり使い切っている制約**(材料と機械)と、**余裕が残っている制約**(需要)があることに注目してください。図で言えば、最適解の頂点は材料の線と機械の線の交点にあり、需要の線からは離れています。

この区別は実務で決定的に重要です。「利益をもっと増やしたければ、どの資源を増強すべきか?」——答えは使い切っている資源だけです。需要上限を6個から7個に緩めても利益は1円も増えません(最適解は需要の線に触れていないから)。では材料を1kg追加したら利益はいくら増えるのか? **実はその金額を、ソルバーは既に計算しています。** これが第1部の山場「双対価格」の話で、1-4で正面から扱います。

## 変数が3個以上になったら?

現実の問題は変数が数千・数百万です。絵はもう描けませんが、今日の構造はそのまま生き残ります。

- 実行可能領域は多角形の高次元版(**多面体**)になる
- 最適解はやはり**頂点**にある
- だから「頂点を賢く渡り歩く」アルゴリズムで解ける——これが次々回に扱う**単体法**です

2次元の絵で掴んだ直感は、そのまま高次元の世界の正しい直感です。

## まとめ

- 制約(一次不等式)の共通部分が**実行可能領域**という多面体を作る
- 目的関数の**等高線**を滑らせ、領域から離れる寸前の接点が最適解
- 接点は(辺と平行な例外を含めても)**頂点を調べれば必ず見つかる**
- 最適解では「使い切った制約」と「余裕のある制約」に分かれる——増強すべきは前者だけ(1-4への伏線)

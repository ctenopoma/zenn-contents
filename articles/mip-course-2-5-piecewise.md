## この記事について

数理最適化を大学1年レベルから列生成法・分枝価格法まで学ぶ教材、第2部・MIP基礎編の5本目(第2部最終回)です。目次はこちら。

@[card](https://zenn.dev/ctenopoma/articles/mip-curriculum-toc)

現実のコストはたいてい線形ではありません。

- 発注には**基本料**がかかる(0個と1個の間に崖がある)
- たくさん買うと**単価が下がる**(数量割引)
- 発電コストは出力の**2乗**で効く

「MIPは線形しか扱えないのでは?」——半分正解で半分間違いです。**折れ線(区分線形)なら、バイナリ変数の力で正確に表せます**。そして滑らかな非線形も、折れ線で好きな精度に近似できます。今回はこの「非線形をMIPに持ち込む技」を、答え合わせ付きでやります。

:::message
コードと数値はすべて手元で実行した実測です。
:::

## パターン1:最低ロット(半連続変数)

前回の固定費リンクの復習+αから。「発注しないか、するなら50個以上400個以下」は:

$$50y \le x \le 400y, \quad y \in \{0,1\}$$

$y=0$ なら $x=0$、$y=1$ なら $50 \le x \le 400$。これで $x$ は「0か、50〜400」という**穴あきの範囲**を取ります(半連続変数)。「中途半端な量は作らない/運ばない」という実務要件の定番です。

## パターン2:数量割引(逓減料金)

本丸です。サプライヤーA社の料金表がこうだとします。

- 発注するなら基本料 **500円**
- 最初の100個: **10円/個**
- 100個を超えた分(〜300個): **8円/個**
- 300個を超えた分(〜500個): **6円/個**

「使った分だけ段階的に安くなる」**逓減(incremental)割引**です。これをMIPで書く定番が**セグメント方式**。区間ごとに「その区間で何個買ったか」$u_k$ と「その区間に到達したか」$z_k$ を持ちます。

```python
SEG = [(0, 100, 10.0), (100, 300, 8.0), (300, 500, 6.0)]  # (下限, 上限, 単価)

y = m.addVar("y", vtype="B")                     # 発注するか
u = [m.addVar(f"u{k}", lb=0, ub=hi - lo) for k, (lo, hi, p) in enumerate(SEG)]
z = [m.addVar(f"z{k}", vtype="B") for k in range(len(SEG))]

for k, (lo, hi, p) in enumerate(SEG):
    m.addCons(u[k] <= (hi - lo) * z[k])          # 区間を使うには「到達」が必要
    if k + 1 < len(SEG):
        m.addCons(u[k] >= (hi - lo) * z[k + 1])  # 次の区間に進むには前の区間を使い切る
m.addCons(z[0] <= y)

x = quicksum(u)                                  # 総発注量
cost = 500 * y + quicksum(SEG[k][2] * u[k] for k in range(len(SEG)))
```

肝は2本目の制約です。これが無いと、ソルバーは**安い区間だけつまみ食い**します(6円/個の区間だけ使って100個買う、など)。「前の段を使い切らないと次の段に進めない」を明示する必要があります。

### 答え合わせ:モデルは料金表を再現しているか

定式化の正しさは、**総量を0〜500まで固定してコスト最小化を解き、意図した料金表と重ねる**ことで検証できます(51点すべて実測)。

![数量割引の答え合わせ](/images/mip-course-2-5-piecewise/fig1_discount.png)

全点が料金表の上に乗りました。0個→1個で基本料500円のジャンプ、100個・300個で傾きが緩む折れ線。**「定式化したら、パラメータを振って意図どおりの挙動か目で確かめる」**——1-2の`writeProblem`と並ぶ、定式化デバッグの基本動作です。

### 使ってみる:2社からの調達

B社(基本料200円+一律9円/個)という選択肢を足して、需要分を最安で調達させます。

```text
需要250個: A=0個   B=250個  計2450円
需要400個: A=400個 B=0個    計3700円
```

需要250ではB社、400では割引が効いてA社に逆転。**料金表の折れ線を正確に踏まえた損益分岐の判断**をソルバーがやってくれています。この構造は電力調達、物流の運賃表、クラウドの従量課金など、料金表があるところすべてで使い回せます。

:::message
もうひとつの割引タイプに「**全量割引(all-units)**」があります(300個買えば全量が6円/個になる)。この場合はコスト関数が**不連続に下がる**ため、「どの区間にいるか」を表すバイナリでちょうど1つの区間を選ぶ($\sum z_k = 1$)方式で書きます。考え方は同じです。
:::

## パターン3:滑らかな非線形の区分線形近似

料金表は元々折れ線でしたが、発電コスト $f(x) = 0.02x^2$ のような滑らかな関数はどうするか。**折れ線で近似**します。

定番は**λ方式(凸結合方式)**です。区間の端点(ブレークポイント)$b_0, \dots, b_K$ を決め、

$$x = \sum_k \lambda_k b_k, \quad \hat{f}(x) = \sum_k \lambda_k f(b_k), \quad \sum_k \lambda_k = 1,\ \lambda_k \ge 0$$

「隣り合う2つの $\lambda$ だけが正」という条件(SOS2制約)を課すと、$\hat{f}$ はちょうど折れ線になります。

```python
lam = [m.addVar(f"l{k}", lb=0, ub=1) for k in range(K + 1)]
m.addCons(quicksum(lam) == 1)
m.addCons(x == quicksum(bp[k] * lam[k] for k in range(K + 1)))
fx = quicksum(f(bp[k]) * lam[k] for k in range(K + 1))   # ← f(x)の近似
m.addConsSOS2(lam)   # 隣接2つのλのみ非ゼロ
```

:::message
**凸なコストを最小化するだけなら、SOS2制約は省略できます**(凸関数の折れ線近似は下から使うのが常に得なので、放っておいても正しい区間が選ばれる)。SOS2やバイナリが本当に必要になるのは、非凸な関数や、最大化と最小化が混ざる場合です。「凸なら整数変数なしで済む」は計算時間に直結する重要な節約です。
:::

### 精度と本数のトレードオフ

折れ線を何本にするかは精度と問題サイズのトレードオフです。実測しました。

![区分線形近似](/images/mip-course-2-5-piecewise/fig2_pwl.png)

```text
最大近似誤差: 2本:12.50 → 4本:3.12 → 8本:0.78 → 16本:0.20
検証(x=30): 2本の折れ線: 近似30.00 (真値18.00) / 8本: 近似18.75
```

**本数を2倍にすると誤差は約1/4**(2次関数の場合)。やみくもに増やさず、「業務的に許せる誤差」から逆算して本数を決めます。誤差が大きく効く領域(よく使う運転範囲など)だけブレークポイントを密にするのも実務の定石です。

## まとめ:後編チートシート

| 現実 | 定式化 |
| ---- | ---- |
| 発注しないか、L〜U個 | $Ly \le x \le Uy$(半連続) |
| 基本料+従量 | $f y + c x$、$x \le M y$ |
| 逓減割引(使った分だけ安く) | セグメント方式($u_k, z_k$、「使い切ったら次へ」) |
| 全量割引(閾値超えで全部安く) | 区間選択方式($\sum z_k = 1$) |
| 滑らかな非線形 | λ方式+SOS2(**凸の最小化ならSOS2不要**) |

- 定式化したら**パラメータを振って料金表と重ねて検証**する
- 折れ線の本数は誤差要件から逆算(倍にすれば誤差1/4)

これで第2部・MIP基礎編は完了です。LPの土台(第1部)+整数の扱い(第2部)が揃ったので、次からは**実務の定番問題を片っ端から解いていく**第3部に入ります。

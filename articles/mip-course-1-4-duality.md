## この記事について

数理最適化を大学1年レベルから列生成法・分枝価格法まで学ぶ教材、第1部・LP編の4本目です。目次はこちら。

@[card](https://zenn.dev/ctenopoma/articles/mip-curriculum-toc)

この回は**この教材の最重要回**です。扱うのは次の実務の問いです。

> 「利益をもっと増やしたい。材料をあと1kg調達できるなら、**いくらまで払っていいか?**」

答えから言うと、この金額は**ソルバーが最適解と同時に計算し終わっています**。取り出し方と読み方さえ知っていれば、追加の計算はゼロです。この数値を**双対価格(シャドウプライス)**と呼びます。そして双対価格は、列生成法(第5部)のエンジンそのものです。

:::message
コードはすべて手元で実行し、数値・図は実行結果をそのまま貼っています。
:::

## 題材:前回の生産計画のつづき

前回と同じ3製品の生産計画を使います。

$$\max\ 5x + 4y + 3z \quad \text{s.t.} \quad
\begin{cases}
2x + 3y + z \le 24 & (材料) \\
4x + 2y + 2z \le 32 & (機械) \\
x + 2y + 2z \le 20 & (組立) \\
x, y, z \ge 0
\end{cases}$$

最適解は $(4, 4, 4)$ で利益48万円。**3つの資源すべてを使い切っています**。さて、来期に向けて資源を増強するなら、材料・機械・組立のどれに投資すべきでしょうか。

## まず実験:1単位ずつ増やして解き直す

一番素朴な方法でやってみます。各資源を1単位だけ増やした問題を作り、それぞれ解き直して利益の増分を測ります。

```python
def solve(b_mat=24.0, b_mac=32.0, b_asm=20.0):
    m = Model()
    x, y, z = m.addVar("x"), m.addVar("y"), m.addVar("z")
    m.addCons(2*x + 3*y + 1*z <= b_mat, name="材料")
    m.addCons(4*x + 2*y + 2*z <= b_mac, name="機械")
    m.addCons(1*x + 2*y + 2*z <= b_asm, name="組立")
    m.setObjective(5*x + 4*y + 3*z, "maximize")
    m.optimize()
    return m.getObjVal()
```

```text
基準の利益: 48.0000
材料 24→25 kg → 利益 48.5000 (Δ = +0.5000)
機械 32→33 h  → 利益 48.9167 (Δ = +0.9167)
組立 20→21 h  → 利益 48.3333 (Δ = +0.3333)
```

![+1実験の結果](/images/mip-course-1-4-duality/fig1_plus1.png)

答えが出ました。**投資効率は機械(+0.917万円/h)が最も高い**。材料1kgの価値は0.5万円なので、市場で1kgあたり0.5万円未満で調達できるなら買う価値があり、それ以上なら買うだけ損です。

この「資源1単位あたりの利益の増分」がシャドウプライス(影の価格)です。実在の市場価格ではなく、**この工場のこの状況における内部的な価値**なのでこう呼ばれます。

## 実は解き直し不要:ソルバーは既に知っている

上の実験では問題を3回解き直しました。しかし実は、**最初の1回を解いた時点で、SCIPは3つの値を全部計算し終えています**。取り出してみます。

```python
from pyscipopt import Model, SCIP_PARAMSETTING

m = Model()
# 双対値を取るときは、SCIPの前処理でLPが変形されないようにする
m.setPresolve(SCIP_PARAMSETTING.OFF)
m.setHeuristics(SCIP_PARAMSETTING.OFF)
m.disablePropagation()
# ...(モデル構築は同じ)...
m.optimize()
duals = {c.name: m.getDualsolLinear(c) for c in [c1, c2, c3]}
```

```text
SCIPの双対価格: {'材料': -0.5, '機械': -0.9167, '組立': -0.3333}
```

符号を除けば、実験で測った増分と完全に一致します。

:::message
**符号について**: SCIPは内部的に最小化で扱うため、最大化問題の双対価格は符号が反転して返ります。「絶対値を読む」で実務上は困りません。
**前処理について**: SCIPはMIPソルバーなので、既定では前処理(presolve)がLPを変形してしまい、元の制約に対応する双対値が取れないことがあります。双対値が目的のときは上のように前処理を切るのが定石です。
:::

## 前回の伏線回収:被約費用の正体

前回(1-3)の単体法の最終ログを覚えているでしょうか。

```text
反復3: 頂点(4.0, 4.0, 4.0) 利益=48.0
   被約費用: {'s材料': -0.5, 's機械': -0.916667, 's組立': -0.333333}
```

スラック変数(資源の余り)の被約費用が **-0.5, -0.917, -0.333**。双対価格と同じ数が出ています。偶然ではありません。

「s材料を1増やす」=「材料を1kg**使わずに余らせる**」ことなので、その被約費用は「材料1kgを手放したときの利益変化」=**−(材料の価値)**。つまり、

> **双対価格は、単体法が最適性を証明するために計算していた量の言い換え**

です。最適解と双対価格が同時に手に入るのは、おまけ機能ではなく単体法の構造そのものなのです。

## 双対価格の有効範囲:スイープで見る

「材料1kgあたり0.5万円」は、材料をいくら増やしても成り立つわけではありません。資源量を広い範囲で振って、最適利益がどう変わるかを実測しました。

![資源量スイープ](/images/mip-course-1-4-duality/fig2_sweep.png)

グラフは**折れ線(区分線形)**になります。読み方:

- 現在値(24kg)付近の傾きが 0.5万円/kg = 双対価格
- **32kgを超えたあたりで傾きが0になる**。材料が豊富になると材料はもうボトルネックではなくなり(制約が非有効になり)、それ以上買っても利益は1円も増えない
- 逆に材料が乏しい領域(16kg以下)では傾きは2.33万円/kgまで急になる。**希少なほど1単位の価値は上がる**

実務への含意は明快です。「双対価格×増強量」で効果を見積もれるのは**傾きが変わらない範囲だけ**。大規模な投資判断(材料を2倍にする等)なら、双対価格で概算せず、このスイープのように**シナリオを解き直す**のが正しい作法です(次回1-5のテーマ)。

なお1-1で見た「余裕のある制約」(需要上限)の双対価格は**0**です。使い切っていない資源を増やしても利益は増えない——スイープの平坦部はこれを言っています。

## 双対問題:資源に値段をつけるもう一つのLP

ここまで「双対価格」を実験的に見てきましたが、正体をもう半歩だけ掘ります。

工場の資源(材料24kg、機械32h、組立20h)を、誰かが全部買い取りに来たとします。資源の単価を $y_{材料}, y_{機械}, y_{組立}$ と置くと、買い取り価格の総額は

$$24 y_{材料} + 32 y_{機械} + 20 y_{組立}$$

工場側が売却に応じる条件は「**どの製品についても、作って売るより資源を売る方が損しない**」こと。例えば製品Aは材料2kg・機械4h・組立1hで利益5万円なので、

$$2y_{材料} + 4y_{機械} + y_{組立} \ge 5 \quad (製品B、Cも同様)$$

買い手はこの条件下で総額を最小にしたい。これは**それ自体がLP**です。解いてみると:

```text
双対の最適値: 48.0
y = [0.5, 0.9167, 0.3333]
```

2つの驚きがあります。

- 最適な買い取り単価は、**双対価格そのもの**
- 買い取り総額の最小値 **48万円は、元の問題の最大利益とぴったり一致**

この「元の問題(主問題)の最大値=双対問題の最小値」を**強双対性**といいます。直感的には、「工場をこのまま操業して稼げる最大額」と「工場の資源を適正に査定した総額」が一致する、ということです。ソルバーが「利益48万円、これが最適」と**証明**できるのは、総額48万円の査定書(双対解)を同時に持っているからです。

## 応用:新製品を双対価格で査定する

双対価格が本当に強力なのは、**まだ存在しない選択肢を評価できる**ことです。

営業から新製品Dの企画が来ました。利益6万円/個、材料3kg、機械2h、組立3h。作る価値はあるでしょうか。**解き直す前に**、双対価格で資源の機会費用を見積もれます。

$$\text{Dの資源コスト} = 3 \times 0.5 + 2 \times 0.9167 + 3 \times 0.3333 = 4.33 \text{万円}$$

利益6万円 > 機会費用4.33万円。差し引き **+1.67万円/個の価値がある**ので、Dは生産ラインに入れるべきです。実際にDを追加して解き直すと:

```text
D追加後の利益: 54.6667  解: x=5.33, y=0.0, z=1.33, w(D)=4.0
```

利益は48→54.7万円に跳ね、Dは4個フル生産、代わりに製品Bが撤退しました。

そしてこの「利益 − 双対価格で測った資源コスト」は、前回の言葉でいう**被約費用**そのものです。

$$\bar{c}_D = c_D - \sum_i a_{iD}\, y_i = 6 - 4.33 = +1.67$$

**列生成法(第5部)は、この査定を武器に「無数にある『まだ存在しない変数』の中から被約費用が最良のものを探し出す」手法**です。カッティングストックでは「新しい切り方パターン」が製品Dに当たり、その査定に使う単価が双対価格です。ここまで来れば、列生成法の準備は実はもう半分終わっています。

## まとめ

- **双対価格 = 制約1単位あたりの目的関数の増分**。最適解と同時にソルバーが計算済み(`getDualsolLinear`、前処理オフを忘れずに)
- 使い切っていない制約の双対価格は0。投資すべきは有効な制約だけ
- 有効なのは**傾きが変わらない範囲だけ**。大きな変更はスイープして解き直す
- 主問題の最大値=双対問題の最小値(強双対性)。最適性の証明の正体
- 「利益 − 双対価格×使用量」=被約費用。**新しい変数の価値を、追加する前に査定できる**——これが列生成の心臓部

第3部では実務の定番問題を1つずつ、「定式化 → 求解 → 可視化 → スケールや変化に強いか」の流れで手に馴染ませていきます。初回は最も基本の**割当問題**——n人にn個のタスクを1対1で割り当ててコスト最小化——です。

ただの練習問題に見えますが、この問題には最適化の理論で最も美しい性質のひとつが隠れています。

> **整数制約を付けなくても、LPを解くと勝手に0/1の解が出てくる。**

今回はこの不思議を実測で確かめ、なぜそうなるかを絵で理解し、そして**どんな制約を足すとこの魔法が解けるのか**まで見届けます。実務で「昨日まで一瞬で解けていたモデルが、要件を1つ足したら急に重くなった」の正体です。

:::message
コードと数値はすべて手元で実行した実測です。
:::

## 定式化

作業員 $i$、タスク $j$、コスト $c_{ij}$(0-3の適性コストと同じ)。

$$\min \sum_{i,j} c_{ij} x_{ij} \quad \text{s.t.} \quad \sum_j x_{ij} = 1\ (\forall i), \quad \sum_i x_{ij} = 1\ (\forall j)$$

各行(人)の合計が1、各列(タスク)の合計が1。本来 $x_{ij} \in \{0,1\}$ のはずですが、今回はあえて**連続変数** $0 \le x_{ij} \le 1$ のLPとして解きます。「佐藤さんがタスク3を0.37だけやる」ことを許した緩い問題です。

## 実験1:LPなのに0/1しか出ない

8×8のランダムなコスト行列で100問作り、全部LPで解いて、解に分数が現れるか数えました。

```text
純粋割当 100問: LPで分数解が出た回数 = 0
```

**100問中100問、全変数が0か1**でした。1問の解を可視化するとこうです。

![LPの解が整数になる](/images/mip-course-3-1-assignment/fig1_integral.png)

整数にしろと一言も言っていないのに、完璧な1対1マッチングが返ってきます。乱数のいたずらではありません。**割当問題では数学的にこうなることが保証されています**。

## なぜか:多面体の頂点が全部整数格子点にいる

1-1の絵を思い出してください。LPの最適解は実行可能領域(多面体)の**頂点**に出ます。つまり「LPの解が必ず整数」ということは、**この多面体の頂点がすべて整数格子点の上にある**ということです。

割当問題の制約行列(各列に1が2個、行グループと列グループに1個ずつ、という二部構造)は**完全単模(totally unimodular)**と呼ばれる特殊な形をしていて、この形の制約が作る多面体は、右辺が整数なら頂点がすべて整数になります。2-1で見た「LP最適と整数最適が別の場所にいる」図とは真逆の、**LP緩和と整数問題の実行可能領域の角が完全に一致している**幸福な世界です。

証明には立ち入りませんが、実務家として覚えるべきは「**この幸福が起きる問題ファミリー**」です。

| 問題 | 例 |
| ---- | ---- |
| 割当・二部マッチング | 人×タスク、講師×コマ |
| 輸送問題 | 工場→倉庫の輸送量配分 |
| 最大流・最小費用流 | ネットワークの容量配分 |
| 最短路 | 経路探索 |

これらは**ネットワーク構造**という共通点を持ち、全部「LPを解くだけ」で整数解が手に入ります。整数変数ゼロ=分枝限定法いらず=**LPの速度で解ける**。数万×数万の割当でも実用時間で終わる理由がこれです。

:::message
割当問題専用にはさらに速いアルゴリズム(ハンガリアン法など。`scipy.optimize.linear_sum_assignment` で使えます)もあります。純粋な割当だけならそちらが手軽ですが、次節のように**制約を足したくなった瞬間**にMIP定式化の柔軟さが効いてきます。
:::

## 実験2:制約を1本足すと魔法が解ける

現実の割当には続きがあります。「各割当には外注費がかかる。**外注費の合計は予算以内で**」。ごく普通の要件です。制約を1本足します。

```python
m.addCons(quicksum(fee[i, j] * x[i, j] for i in range(n) for j in range(n)) <= budget)
```

もう一度LPで解くと:

```text
LP: obj=35.455, 整数解か: False
LPに現れた分数値: [0.091, 0.909]
IP(整数制約あり): obj=36.000
```

![壊れた整数性](/images/mip-course-3-1-assignment/fig2_broken.png)

**分数が出ました。** 「作業員0はタスク4を0.91、タスク7を0.09だけ担当」——予算をぴったり使うために、LPは割当を"ブレンド"したのです。予算制約は係数がバラバラの一般の不等式なので、完全単模の構造(±1と0だけの綺麗な行列)を壊します。多面体に**整数でない頂点**が生まれ、LPはそこに座ります。

こうなったら整数制約(`vtype="B"`)を付けて、分枝限定法の世界(第2部)で解くしかありません。この例では LP=35.45 に対し整数最適=36。ギャップは小さいので、SCIPは一瞬で解き切ります。

### 実務での意味

この「壊れる瞬間」は実務で頻繁に踏みます。

- 純粋な割当・輸送 → LP速度。**要件追加(予算、ペア禁止、公平性)→ 突然MIP**
- 「モデルに1行足しただけで遅くなった」ときは、**その1行がネットワーク構造を壊していないか**を疑う
- 逆に、モデルの大部分がネットワーク構造なら、壊す制約が少ないほどLP緩和が強く(=分数が出にくく)、速く解ける。**「構造を保つ書き方を選ぶ」は高速化の第一手**です

## まとめ

- 割当・輸送・フロー・最短路は、**整数制約なしのLPで整数解が保証される**(完全単模性)——実測100/100問
- 理由は「多面体の頂点が全部整数格子点にいる」から。LP緩和と整数問題の乖離がゼロ
- **一般の係数を持つ制約を1本足すだけで壊れる**(実測で分数解 0.091/0.909 が出現)
- 実務の勘所:ネットワーク構造は財産。壊す制約は自覚的に足す
